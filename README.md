# Hundred Masks — official site

Static site for [Hundred Masks](https://aralem.dev/hundred-masks-support/), a paper-theatre strategy game for iPhone by Aralem.

- `index.html` — the game
- `support/` — help and contact
- `privacy/` — privacy policy
- `assets/` — stylesheet, icon, screenshots and self-hosted fonts (EB Garamond, SIL Open Font License — see `assets/fonts/OFL-EBGaramond.txt`)

No build step. Edit the HTML, commit, push; GitHub Pages serves the `main` branch. Nothing on the site loads from third parties.

Screenshots are taken from the current build in the iOS Simulator (iPhone 17 Pro) and downscaled to 800 px wide.
